온라인과외,
어떻게 골라야
후회가 적을까요?

온라인과외는 화질이나 광고 문구보다 학생의 풀이 과정을 선생님이 어떻게 확인하고, 수업 뒤 무엇을 남기는지로 판단하는 편이 좋습니다. 먼저 필요한 과목과 목표를 한 가지로 좁히고, 체험 수업에서 질문·피드백·과제 관리가 실제로 작동하는지 확인하세요.

01 — FIT FIRST

좋은 온라인과외의 기준은
학생에게 맞는 ‘수업의 움직임’입니다

실시간 1:1 수업이라도 선생님이 설명만 이어가면 학생의 막힌 지점을 놓치기 쉽습니다. 아래 네 가지를 실제 수업 장면으로 확인하세요.

01 / 목표

무엇을 해결할지 선명한가

내신 대비, 개념 결손, 문제 풀이 속도 중 우선순위를 하나 정합니다. 목표가 모호하면 진도만 빠르게 나갈 수 있습니다.

02 / 참여

학생이 직접 설명하는가

화면 공유와 필기 도구보다 중요한 것은 학생이 풀이 이유를 말하고 선생님이 오개념을 바로 짚는 과정입니다.

03 / 수업 후

복습이 다음 수업에 이어지는가

과제의 양보다 확인 방식이 중요합니다. 틀린 문제를 다시 풀게 하고 다음 수업의 시작점으로 삼는지 물어보세요.

04 / 소통

보호자와 정보가 공유되는가

미성년 학생이라면 진도, 이해도, 과제 상태를 어떤 주기와 방식으로 전달하는지 확인하는 것이 좋습니다.

학생 상황별 우선순위

초등학생은 집중 시간과 화면 상호작용, 중학생은 학교 진도와 오답 관리, 고등학생은 목표 시험의 범위와 시간 배분을 먼저 확인해 보세요. 학년보다 현재의 학습 문제를 구체적으로 말하는 것이 상담에 더 도움이 됩니다.

02 — TOTAL COST

수업료는 ‘시간당 금액’만으로
비교하기 어렵습니다

같은 60분 수업이라도 횟수, 교재, 피드백, 보강 조건이 다르면 실제 부담과 학습 경험이 달라집니다. 정해진 시세를 가정하기보다 같은 조건으로 견적을 받아 비교하세요.

견적을 받을 때 나란히 적을 항목

  • 수업 구성1회 시간 × 주간 횟수 × 결제 기간
  • 추가 비용교재·진단·플랫폼 비용 유무
  • 운영 조건결석·보강·중도 종료 기준
  • 포함 서비스과제 확인·수업 기록·상담 범위

예: 월 총액이 같아도 회당 수업 시간과 수업 후 피드백 범위가 다를 수 있습니다.

03 — TRY BEFORE DECIDING

체험 수업은 학생의 반응을
관찰하는 시간입니다

상담 전에 최근 시험지나 틀린 문제 2~3개, 현재 교재와 목표를 준비하세요. 수업 뒤에는 학생에게 “이해했어?” 대신 “어떤 문제를 혼자 다시 풀 수 있겠어?”라고 물어보면 수업 효과를 더 구체적으로 알 수 있습니다.

체험 수업에서 확인할 질문

  1. 01선생님이 학생의 기존 풀이를 먼저 물었나요?
  2. 02틀린 이유를 학생의 말로 설명하게 했나요?
  3. 03막힐 때 설명 방식이나 난도를 바꾸었나요?
  4. 04수업 끝에 다음 학습 행동을 정했나요?
“

학생이 조용히 듣기만 한 수업보다, 틀린 생각을 드러내고 고쳐 본 수업이 선택에 필요한 정보를 더 많이 줍니다.

실시간 1:1 수업에서 풀이 과정을 어떻게 살피고 과목·학년별로 수업을 조정하는지 구체적인 예가 필요하다면, 밀착온의 온라인과외 수업 안내를 살펴보세요. 위 질문을 기준으로 서비스 설명과 상담 조건을 비교해 볼 수 있습니다.

04 — FINAL CHECK

신청 전, 이 여섯 가지만
확인하세요

✓현재 문제와 4~8주 목표를 말할 수 있다

✓체험 수업에서 학생이 직접 풀고 설명했다

✓수업 후 피드백과 과제 확인 방식을 안다

✓월 총액과 추가 비용을 확인했다

✓결석·보강·환불 조건을 문서로 확인했다

✓기기·인터넷·조용한 학습 공간을 점검했다

조건이 불명확하다면 결제를 서두르지 말고 서면 안내를 요청하세요. 학생과 선생님의 궁합은 체험 수업에서 가장 잘 드러납니다.

COMMON QUESTIONS

자주 묻는 질문

온라인과외는 대면 과외보다 효과가 떨어지나요?

방식 자체보다 학생이 풀이를 보여주고 질문하며 피드백을 받는 구조가 더 중요합니다. 다만 화면에 집중하기 어려운 학생이라면 짧은 수업, 손글씨 공유 방식, 학습 공간을 먼저 시험해 보세요.

첫 상담에는 무엇을 준비해야 하나요?

학년과 과목, 최근 어려웠던 단원, 사용 교재, 가능한 시간대를 정리하세요. 최근 시험지나 오답 사례가 있으면 학습 목표를 구체화하는 데 도움이 됩니다.

얼마나 오래 수업을 들어야 판단할 수 있나요?

체험 수업에서는 상호작용을 보고, 정규 수업을 시작한 뒤에는 약속한 목표와 과제·오답의 변화를 정기적으로 점검하세요. 짧은 기간의 점수만으로 판단하기보다 학생이 스스로 설명하고 다시 푸는 능력이 달라지는지 보세요.
